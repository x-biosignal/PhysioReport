# PhysioReport

Clinical report generation for the
[x-biosignal](https://github.com/x-biosignal) ecosystem: parameterized,
bilingual (JA/EN), colorblind-safe reports (gait, HRV, EMG) with
normative overlays and MDC/MCID-annotated change.

## Installation

``` r

install.packages("PhysioReport",
  repos = c("https://x-biosignal.r-universe.dev", "https://cloud.r-project.org"))
```

Part of the x-biosignal rehabilitation-standard implementation plan.
